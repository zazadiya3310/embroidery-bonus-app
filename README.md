# Embroidery Bonus App 🧵

यह एक Streamlit एप्लीकेशन है जो एम्ब्रॉयडरी मशीन के लिए बोनस (Bonus) की गणना करने के लिए बनाई गई है।  
This is a Streamlit application built to calculate bonuses for embroidery machines.

## विशेषताएं (Features):
* एम्ब्रॉयडरी मशीन के काम का बोनस आसानी से गिनें। / Easily calculate embroidery machine work bonuses.
* उपयोग करने में बहुत ही आसान और तेज़। / Very simple and fast to use.

## इसका उपयोग कैसे करें? (How to Use):
1. एप्लीकेशन खोलें। / Open the application.
2. आवश्यक विवरण दर्ज करें। / Enter the required details.
3. बोनस की राशि प्राप्त करें। / Get the bonus amount.
